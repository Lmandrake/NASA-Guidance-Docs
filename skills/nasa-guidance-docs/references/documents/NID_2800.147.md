**Scope, plainly.** Implements the 21st Century IDEA Act, the DOTGOV Act, and OMB M-23-10/M-23-22 by consolidating NASA's public-facing websites into "a unified public web experience" centered on www.nasa.gov and science.nasa.gov (p.1). Covers .gov and non-.gov public/mobile sites and "software classes" (p.3); explicitly excludes machine-to-machine "web services" and third-party community platforms where NASA is one user among many, e.g. github.com/nasa — but a NASA-built GitHub Pages static site is in scope (p.3, paraphrase).
