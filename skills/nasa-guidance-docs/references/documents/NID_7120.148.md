**Scope, plainly.** Interim-directive update to NASA's core space-flight program/project management requirements (title page cross-references NPR 7120.5F and "NASA Space Flight Program and Project Management Handbook"), covering program/project life cycles, roles and responsibilities, Technical Authority (§3.3), the formal-dissent process (§3.4), and tailoring (§3.5), plus template appendices for Program Commitment Agreements, Formulation Authorization Documents, and Program/Project Plans.

**AI and machine-learning touchpoints.** "Autonom*" appears twice (duplicated text, pp.115 and 132), in Appendix C guidance for a project's Orbital Collision Avoidance Plan: "...how the spacecraft's location tracking data will be generated, and whether there will be any autonomous flight control." No "artificial intelligence," "machine learning," "neural," or "algorithm" found. This is a conventional spacecraft-autonomy mention in a collision-avoidance planning checklist, not an AI/ML-specific clause (our reading).

**Connections and traps.**
- 🔴 By the same comparison, this NID should be treated as the same instrument as NPR 7120.5F, not counted as a separate requirements source — counting both double-counts one instrument.
- Status conflict: the cover's own printed dates (eff. 2024-12-09, exp. 2025-12-09) read as expired; the OPD register's extension note (to 2027-08-01) is the only place the current expiration lives. Do not cite the cover date alone as this NID's force.
- NPR 7120.10B §3.1.1's Note on Technical Authority concurrence and dissent points to "NPR 7120.5, section 3.3, and... section 3.4" — this NID's own §3.3/§3.4 would be the current text of those sections, not NPR 7120.5F's superseded ones (our reading; not independently cross-checked here).
